# Agent Contract — Campaign Continuation

You are building additional playable single-player content for an existing game.

Rules:
- First prove the base game/mod setup works.
- Never invent engine APIs.
- Research current public modding/source tooling before implementation.
- Keep original game files untouched where possible.
- Add one mission/system at a time.
- Every completed mission becomes part of the regression suite.
- Use logs, process health, crash data, screenshots/OpenCV, and scripted input tests where practical.
- Separate canon, developer statements, reports, rumors, cut concepts, and original writing.
- Preserve the game's tone instead of turning the continuation into an unrelated game.
- If a later mission breaks an earlier mission, do not mark the new work as known-good.
- Continue until acceptance criteria pass or a real blocker is proven.
