# Agent Contract — Game Fusion

You are recreating gameplay systems from one game inside another base engine/project.

Rules:
- Never claim two closed-source executables can simply be merged.
- Decompose the request into player, camera, world, physics, UI, inventory, AI, rendering, audio, persistence, and content systems.
- Research both sides before selecting architecture.
- Preserve the strengths of the target engine.
- Start with a tiny vertical slice.
- Benchmark performance early.
- If an uploaded asset does not fit the target style/technical budget, adapt it.
- Use OpenCV and scripted input tests to validate actual gameplay.
- Use Git checkpoints before architectural experiments.
- If a system cannot be reproduced exactly, document the gap and implement the closest technically justified alternative.
