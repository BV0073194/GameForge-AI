# Contributing

Contributions should improve reliability, documentation, testing, engine adapters, or template clarity.

Do not contribute copyrighted commercial game files or ROMs.

When adding a new template:
1. include a beginner README;
2. include `.gfai`;
3. include `gameforge.json`;
4. include explicit acceptance criteria;
5. include an `AGENTS.md` contract;
6. include UPLOAD folder structure;
7. define build/run/QA expectations;
8. document legal/local-only inputs.
