# Project Goal

Transform a decomp/homebrew/ROM-based game project into a substantially different playable experience while preserving technical compatibility with the target platform. Prefer open decomp/recomp/homebrew source when available. Allow local use of the user's legally obtained ROM for extraction/build verification, but do not redistribute the commercial ROM. Deep-research the current source tree, platform constraints, asset formats, modding tools, emulator behavior, and proven public examples. Adapt uploaded assets to the original game's art style and hardware budget. Build ROM/output artifacts locally, launch in an emulator, use logs/OpenCV/input replay/regression testing, and keep fixing until the requested experience is playable or a genuine blocker is proven.
